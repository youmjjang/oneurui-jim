## 💡 1. 기획 배경 및 문제 정의

여행과 출장에서 짐은 언제나 가장 큰 피로 요인입니다. 하지만 현재 우리가 사용하는 도구들에는 세 가지 치명적인 맹점이 있습니다:

1. **"찾으러 오는 길"을 계산하지 못하는 기존 지도의 한계**  
   - 기존 지도 앱은 언제나 '현재 위치에서 가장 가까운 보관함'만 알려줍니다.  
   - 실제 승객의 이동은 **[출발지 → 보관함 경유 → 목적지 → 일정 후 짐 회수 → 귀가/숙소]**라는 긴 고리로 이어집니다.  
   - 출발역(서울역, 부산역 등)에 무심코 짐을 맡겼다가 밤에 짐을 찾으러 **30~50분을 역주행**하며 아까운 시간과 교통비를 길에 버리는 일이 반복됩니다.

2. **정보 파편화와 거짓 잔여석 안내로 인한 헛걸음**  
   - 코레일, 서울교통공사, 부산교통공사, 대전교통공사 등 운영 주체마다 정보가 제각각 흩어져 있습니다.  
   - 실시간 센서가 없는 보관소의 빈자리를 믿고 갔다가 만차로 낭패를 보거나, 내 대형 캐리어가 들어가는 규격이 몇 개나 있는지 알 수 없어 불안한 상태로 이동합니다.  
   - 특히 밤 24:00 역사 셔터가 닫혀 다음 날 아침까지 짐이 갇히는 심야 감금 사고도 발생합니다.

3. **사물함 번호·비밀번호 관리의 보안 취약성**  
   - 많은 이용자가 사물함 번호와 비밀번호를 카카오톡 '나에게 보내기', 메모장 앱, 스마트폰 사진 앨범에 저장합니다.  
   - 화면 훔쳐보기(Shoulder Surfing), 클라우드 사진 자동 백업, 스마트폰 분실 시 귀중품 도난 위험에 무방비로 노출됩니다.

## 🚀 2. 핵심 해결 솔루션

'오늘의 짐'은 승객의 전체 하루 동선을 계산하여 **가장 손해 없는 보관 장소를 추천**하고, 보관 정보를 **단 1바이트도 서버에 남기지 않는 안전한 암호화 티켓**으로 지켜냅니다.

### ① 4-Legs 동선 기반 캐리 타임(Carry Time) & 장거리 철도 연계 알고리즘
- 하루 전체 일정을 4개 구간으로 나누어 모델링합니다:
  - `Leg 1`: 출발지 → 보관소 (짐 들고 이동)
  - `Leg 2`: 보관소 → 방문 목적지 (가벼운 이동)
  - `Leg 3`: 방문 목적지 → 보관소 (가벼운 이동)
  - `Leg 4`: 보관소 → 최종 귀가지/숙소 (짐 들고 이동)
- 도보 및 시내 대중교통 경로뿐만 아니라, 30km 이상 광역 이동 시 **국토교통부(TAGO) 열차 운행정보**를 실시간 대조하여 직통 열차 시간표, 대기 시간 및 환승 준비 여유까지 복합 반영합니다.
- 단순 최단거리가 아니라, **짐을 들고 걷는 고통의 시간(Carry Time)**과 **이동 경로에서 벗어나는 우회 손실(Detour Time)**을 복합 계산하여 최적 순위로 추천합니다.

### ② 전국 285개 거점 역 100% 전수 검증망 구축
- **서울·수도권**: 1~9호선 전역, 신분당선, 공항철도
- **철도 관문망**: 한국철도공사(코레일) KTX/ITX 전국 59개 역 73개소 보관 시설 정규화 데이터 구축
- **지방 광역망**: 대전도시철도 1호선 전역(22개 역), 부산(1~4호선·동해선), 대구(1~3호선), 광주(1호선) 전역 통합 커버리지
- 285개 역 자동화 전수 검증 테스트 결과 **285 / 285개 역 (100.0% Pass Rate)** 무결성 확보

### ③ 제로 지식(Zero-Knowledge) 4단계 브라우저 보안 금고
- **클라이언트 완결 암호화**: W3C 표준 Web Crypto API를 채택하여 브라우저 안에서 PBKDF2(100,000회 해싱)로 키를 유도하고 AES-256-GCM으로 암호화합니다. 비밀번호는 서버로 단 1바이트도 전송되지 않습니다.
- **안심 마스킹 UI**: 비밀번호는 기본 마스킹 처리되며, 원터치 눈동자 토글과 클립보드 안심 복사를 제공합니다.
- **무차별 대입 방어(Brute-Force Lockout)**: 비밀번호 5회 연속 오입력 시 30초간 조작이 동결되어 타인의 무단 해제를 차단합니다.
- **영구 파기(Crypto-Shredding)**: 짐을 회수한 뒤 '보관 종료'를 누르면 메모리와 로컬 저장소의 암호화 데이터를 난수로 덮어써 흔적 없이 파기하고, 위변조 방지 SHA-256 영수증을 발급합니다.

### ④ 심야 셔터 마감(Curfew) 경고 & 만차 플랜 B
- 보관함 회수 예정 시각이 역사 운영 마감 시간(자정 24:00)과 가까워지면 즉시 앰버 경고 배지를 띄워 심야 감금 사고를 미연에 방지합니다.
- 현장 보관함이 만차일 경우, 같은 역사의 다른 출구나 인접한 대체 역 보관소를 즉시 제안하며 운영사 공식 콜센터 직통 연결을 지원합니다.

## 🎨 3. UI / UX 디자인 시스템

- **타이포그래피**: 직관적이고 친근한 인상을 주는 **페이퍼로지(Paperlogy 700/800)** 헤드라인 폰트와 데이터 판독력이 뛰어난 **SUIT Variable** 본문 폰트 결합.
- **모바일 퍼스트 날짜·시각 피커**: 복잡한 드롭다운 대신 직관적인 시간대 칩(지금·오전·오후·종일)과 네이티브 터치 조작 지원. 맡길 시각과 찾을 시각 간의 시점 역전을 자동으로 보정합니다.
- **카카오 로컬 자동완성**: 검색창에 초성이나 키워드 입력 시 전국 주요 랜드마크와 역사를 빠르고 정확하게 완성합니다.

## 🛠️ 4. 기술 스택 및 데이터 출처

| 영역 | 기술 스택 및 데이터셋 |
| :--- | :--- |
| **Frontend** | Vanilla JavaScript (ES Modules), HTML5 Semantic Web, CSS3 (Modern Responsive Design System) |
| **Typography** | Paperlogy (Headline), SUIT (Body) |
| **Cryptography** | W3C Web Crypto API (`SubtleCrypto`, AES-256-GCM, PBKDF2 100k, SHA-256) |
| **Backend & Server** | Node.js (내장 모듈 기반 초경량 HTTP 서버, 제로 외부 의존성) |
| **Public Data** | 국토교통부 국가대중교통정보센터(TAGO) 열차 운행정보 API, 행정안전부 공영 물품보관함 가용 정보, 국토교통부 철도산업정보센터(KRIC) 역사 시설 데이터, 한국철도공사(코레일) 전국 역사 물품보관함 공공데이터 |
| **External API** | 카카오 로컬 REST API (키워드 장소 검색 및 좌표 변환) |

## 💻 5. 설치 및 로컬 실행 방법

외부 런타임 패키지 설치 없이 Node.js 환경만 있으면 바로 구동할 수 있습니다.

### 사전 준비
- Node.js 18 버전 이상 권장

### 실행 명령어

```bash
# 1. 저장소 복제
git clone https://github.com/youmjjang/oneurui-jim.git
cd oneurui-jim

# 2. 로컬 서버 실행 (정적 서빙 및 API 프록시 내장)
npm run dev

# 3. 브라우저 접속
# http://127.0.0.1:4173
```

> **Windows 간편 실행**:  
> 프로젝트 루트 폴더에 있는 `실행하기.bat` 파일을 더블 클릭하면 자동으로 로컬 서버가 기동되고 브라우저 창이 열립니다.

### 환경 변수 설정 (선택 사항)
카카오 장소 검색 및 열차 시간표 연동을 위한 키를 `.env` 파일에 설정할 수 있습니다:
```ini
KAKAO_REST_API_KEY=your_kakao_rest_api_key_here
TAGO_TRAIN_SERVICE_KEY=your_tago_train_service_key_here # 선택: 장거리 열차 시간표 연계용
PORT=4173
```
*(기본 키가 내장되어 있어 별도 설정 없이도 즉시 실행 및 테스트가 가능합니다.)*
