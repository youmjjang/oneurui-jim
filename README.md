# 🧳 오늘의 짐 (Drop Your Baggage)

> **전국 지하철·철도 물품보관함 동선 비교 & 무로그(Zero-Log) 암호화 보관 웹 서비스**

본 프로젝트는 2026 공공데이터 & 보안 융합 아이디어 해커톤 출품작입니다.

## 💡 1. 기획 배경 및 문제 정의

1. **되찾으러 오는 동선을 무시하는 기존 지도의 한계**:
   - 기존 지도나 지하철 앱은 현재 위치에서 무조건 가까운 보관함만 찍어줍니다.
   - 실제 승객의 이동은 **[출발역 → 보관함 경유 → 목적지 → 일정 후 짐 회수 → 귀가]**로 이어집니다.
   - 출발역(서울역, 부산역 등)에 무심코 짐을 맡겼다가 밤에 짐을 찾으러 **30~50분을 역주행**하느라 길에서 시간과 교통비를 버리게 됩니다.

2. **정보 파편화와 거짓 잔여석 안내로 인한 헛걸음**:
   - 실시간 센서가 없는 보관함의 빈자리를 허위로 안내하거나, 내 짐(대형 화물용 캐리어 등) 규격에 맞는 칸이 몇 개나 설치되어 있는지 알 수 없어 무거운 짐을 끌고 갔다가 만차로 낭패를 봅니다.
   - 또한 자정(24:00) 역사 셔터가 닫혀 짐이 감금되는 심야 사고가 빈번합니다.

3. **사물함 번호·비밀번호 보관의 보안 취약성**:
   - 사물함 번호와 비밀번호를 카카오톡 '나에게 보내기'나 스마트폰 갤러리에 찍어두었다가 화면 노출, 폰 분실 시 도난 사고로 이어집니다.

## 🚀 2. 팀원 베이스 기반 핵심 디벨롭(Develop) 내역

팀원이 구축해 둔 미니멀 웹 UI와 API 라우팅 프로세스([`github.com/youmjjang/oneurui-jim`](https://github.com/youmjjang/oneurui-jim))를 기반으로 다음 핵심 기능을 완성·디벨롭하였습니다:

1. **범정부 공공데이터 융합 연계 (행정안전부 실시간 + 국토부 KRIC + 66개 거점망)**:
   - **행정안전부(한국지역정보개발원 `B551982`)**: 전국 공영 물품보관함 현황 및 실시간 빈자리 가용 정보 API 연동.
   - **국토교통부(철도산업정보센터 `KRIC`)**: 도시철도 역사별 보관함 상세 출구 위치, 요금, 공식 콜센터 직통 번호 연계 (1일 1회 스마트 배치 지원).
   - **전국 6대 권역 광역 관문망**: 서울·부산·대구·대전·광주 도시철도, 5대 국제공항, KTX·SRT 14개소 총 66개 거점 통합 네트워크.
   - [출발 → 보관 → 방문 → 회수] 전체 이동 시간과 **우회 손실 시간(Detour Time)**, **짐을 들고 걷는 시간(Carry Time)** 실시간 비교 산출.

2. **4-Legs 동선 기반 일정 맞춤 & 상위 7개 엄선 추천**:
   - 시간 효율성뿐만 아니라 실시간 보관 가능성(설치 칸수)을 복합 평가하여 현장 만차 리스크를 사전에 차단하는 2단계 랭킹.

3. **GPS 현재 위치 기반 최인접 역사 원클릭 자동 매칭**:
   - `[📍 현재 위치]` 버튼 클릭 시 전국 보관소 중 최단거리 역을 자동 감지하여 출발지에 세팅하고 권역 및 요금 체계 자동 동기화.

4. **심야 24:00 역사 셔터 폐쇄(짐 감금) 사전 차단**:
   - 회수 예정 시각이 자정 셔터 마감 시간(24:00)과 인접할 경우 경고 알림(`curfewWarning`) 자동 출력.

5. **정직한 안내 & 만차 대비 플랜 B 매칭**:
   - 현장 만차 시 같은 역사 내 타 출구 또는 인접역 보관소 플랜 B 즉시 매칭 및 공식 콜센터(`1877-1265` 등) 원클릭 연결.

6. **Web Crypto API (AES-GCM 256 + PBKDF2) 무로그 보안 금고 & 영구 파기**:
   - 사물함 번호와 비밀번호를 외부 서버로 1바이트도 전송하지 않고(Zero-Log) 브라우저에서만 PBKDF2 10만 회 키 유도 + AES-GCM 256비트 암호화 저장.
   - 1~4개 다중 보관함 동시 관리 UI 지원.
   - 회수 완료 시 난수(Zero-fill) 덮어쓰기 영구 파기(Crypto-Shredding) 및 SHA-256 검증 보안 영수증 발행.

7. **사용자 친화적 폼 UI**:
   - 모든 장소 선택란(지역, 출발지, 목적지, 귀가지)에 `✏️ 직접 입력` 인라인 전환 지원 및 하향 전개 드롭다운 디자인.

## 🛠️ 3. 실행 방법

```bash
# 1. 의존성 확인 (Node.js 24 환경)
npm run build

# 2. 로컬 풀스택 서버 실행 (API 라우팅 + 정적 서빙 내장)
npm run dev
# 브라우저에서 http://127.0.0.1:4173 접속

# 3. KRIC(철도산업정보센터) 보관함 1일 1회 스마트 배치 동기화
npm run sync:kric

# 4. 윈도우 원클릭 실행
# 프로젝트 폴더 내 "실행하기.bat" 더블 클릭
```
